# FocusGuard 🛡️ `v1.1.0`

X（旧Twitter）やYouTubeなど、指定したWebサイトへのアクセスを時間帯や1日のタイマーで制限する、Windowsデスクトップ常駐アプリです。

Chrome、Edge、Firefox等あらゆるブラウザに対応し、抜け道のない通信遮断（Windows hosts連携 ＋ WinINet PACプロキシ連携）を提供します。

---

## 🌟 主な機能

1. **時間帯制限（スケジュール）**
   - 「仕事中（09:00〜18:00）だけXをブロック」「就寝前（22:00〜07:00）だけブロック」など、指定した時間帯に自動で遮断。
   - 曜日ごとの有効/無効設定が可能（平日のみ、休日のみなど）。
2. **1日の利用時間タイマー制限**
   - 「1日に合計30分まで閲覧可能、それを超えたら当日はブロック」などの上限設定。
   - 毎日午前0時に利用時間を自動リセット。
3. **クイック集中モード（ポモドーロ機能）**
   - 「25分集中」「50分集中」ボタンを押すと、スケジュールに関わらず即座にブロックを開始。
4. **対象サイトの自由な追加・削除**
   - X（`x.com` / `twitter.com`）のほか、YouTubeやInstagramなど任意のドメインを追加可能。
5. **解除防止パスワード**
   - 意志の弱さで勝手に設定を変えたり解除してしまうのを防ぐため、パスワード保護を設定可能。
   - パスワード設定時は、時間帯制限の変更（ON/OFF・時間・曜日）やタイマー変更、ブロック対象サイトの削除、保護機能OFF、アプリ終了時にパスワード認証が要求されます（※サイトの追加はパスワードなしで自由に行えます）。
6. **タスクトレイ常駐 ＆ 自動起動**
   - 画面を閉じてもタスクトレイに常駐し、バックグラウンドで監視を継続。
   - Windows起動時の自動起動（スタートアップ）対応。

## 🚀 使い方

### 起動方法・画面の再表示
フォルダー内の `run.bat` をダブルクリックします。

- **画面を「×」で閉じた場合**：バックグラウンド（タスクトレイ）で常駐監視を継続します。
- **再度設定画面を開きたい場合**：
  - フォルダー内の **`run.bat` をダブルクリック** すれば、いつでも設定画面が最前面に再表示されます。
  - または画面右下のタスクトレイ（時計横の `^` 内）にある FocusGuard アイコン（🛡️ / 🟢）をクリックまたはダブルクリックしても開けます。
- **完全に終了したい場合**：
  - 設定画面右下の「終了」またはトレイアイコン右クリックから「FocusGuard 終了」を選択します（パスワード設定時はパスワード認証が必要です）。

### （推奨）hosts ファイルの自動連携設定
より強力にPC全体・全アプリで完全遮断を行いたい場合：
1. `setup_hosts.bat` を右クリック
2. **「管理者として実行」** をクリック
※ これを行わなくても、WinINet PACプロキシ連携により通常権限でChromeやEdgeなどのブラウザを遮断可能です。

## 📦 必要環境
- Windows 10 / 11
- Python 3.10 以上
- 依存ライブラリ：
  ```bash
  pip install -r requirements.txt
  ```

---

## 📁 ディレクトリ構成
- `focus_guard.pyw`: メインGUI & タスクトレイ常駐アプリ
- `blocker.py`: 通信遮断エンジン（hostsファイル / PACプロキシ制御）
- `config_manager.py`: 設定・タイマー・パスワード管理
- `version.py`: バージョン定義
- `setup_hosts.bat`: hosts権限付与ツール（管理者実行用）
- `run.bat`: アプリ起動用バッチ
- `tests/`: 単体テスト
